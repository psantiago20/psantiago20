## 🚀 Projetos em Destaque

### 🏥 OmniConnect — Gestão Inteligente de Saúde
Plataforma **Full Stack** desenvolvida em equipe na Code Academy da Alpha Edtech, simulando um ambiente real corporativo com entregas frequentes, dailies e code review.
- **Backend:** Desenvolvido em **Python (FastAPI)** com autenticação JWT, integração com **IA de Visão Computacional** (Nvidia Vision API) para análise de exames médicos e **agentes inteligentes** com **LangChain/LangGraph** e **ChromaDB** (RAG).
- **Frontend:** Aplicativo multiplataforma em **Flutter/Dart** com gerência de estado **Riverpod** e roteamento dinâmico **GoRouter**.
- **Infraestrutura:** **PostgreSQL** rodando em ambiente containerizado com **Docker** e **Docker Compose**. Integração com **Firebase**.

### 🎮 Desenvolvimento de Jogos Educativos
Participação em projeto colaborativo de **criação de jogos educativos** na Alpha Edtech, com foco em temas como física, geografia, matemática e lógica.
- **Engine:** Jogos desenvolvidos com **Flutter + Flame Engine** (Dart).
- **Trabalho em equipe:** Desenvolvimento colaborativo com outros estudantes, utilizando controle de versão com **Git** e entregas contínuas.
- **Temáticas:** Simuladores de física, quizzes educativos, jogos de lógica e exploração geográfica.

### 🤖 Assistente de IA com Interação Humanizada
Desenvolvimento de assistentes inteligentes com foco em **conversação natural e interação humanizada**, capazes de compreender contexto, manter memória de sessão e fornecer respostas personalizadas.
- **Tecnologias:** **Python**, **LangChain/LangGraph**, **ChromaDB** (RAG), **Nvidia NIM API**.
- **Funcionalidades:** Extração de informações, análise de dados, recomendações personalizadas e integração com APIs externas.
- **Foco:** Experiência do usuário fluida, com respostas contextuais e tom de conversa natural.

### ⚔️ Life RPG — Gamificação de Produtividade
Aplicação web gamificada para gestão de tarefas e hábitos com sistema de níveis e XP.
- **Backend:** **Node.js** + **TypeScript** + **Express 5** com autenticação JWT (**bcrypt** + **jsonwebtoken**).
- **ORM:** **Prisma** com banco de dados relacional.
- **Validação:** **Zod** para validação de schemas.
- **Arquitetura:** Clean Architecture com controllers, services, middlewares, routes e schemas separados.
- **Frontend:** **HTML/CSS/JavaScript** puro.

### 📊 Metas de Saúde — Acompanhamento de Métricas Corporais
Sistema Web focado em saúde preventiva e monitoramento corporal individual.
- **Backend:** **Python (Django)** com banco de dados **SQLite/Supabase**.
- **Frontend:** Interface premium com **CSS** (tema Navy & Teal), mapas corporais interativos com **SVG/JavaScript** e dashboards dinâmicos.
- **IA:** Assistente acoplado para análises automáticas de IMC, progresso e recomendações personalizadas.

### 🏋️ Gym App — App de Treino Fitness
Aplicação Django para acompanhamento de treinos com medições corporais e progresso.
- **Backend:** **Python (Django)** com **SQLite**, testes automatizados (**pytest**), linting (**flake8**, **isort**).
- **Arquitetura:** Modular com apps separados (accounts, workouts, measurements, progress).
